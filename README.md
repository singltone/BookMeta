# BookMeta Android — MVP

Світла Android-програма для пошуку та редагування метаданих електронних книг.

## Що працює в цьому MVP
- Вибір файла через системний Android Storage Access Framework.
- Пошук метаданих через Google Books API (потрібен інтернет).
- Ручне редагування назви, автора, анотації, видавництва, року, ISBN, мови та жанрів.
- Читання базових метаданих EPUB та FB2.
- Запис базових полів у EPUB (OPF) та FB2.
- Підтримка світлої теми.

## Обмеження
Запис реалізовано лише для EPUB та FB2. PDF, DJVU, MOBI та AZW3 у цій версії можна вибрати, але повноцінне читання/запис їхніх метаданих ще не реалізовано. Універсальне редагування цих форматів потребує окремих форматних бібліотек; MOBI/AZW3 мають додаткові нюанси сумісності/DRM. EPUB-пакування в цьому MVP перебудовується стандартним ZIP API, тому для максимальної EPUB-сумісності варто додати спеціальну обробку `mimetype` як першого STORED entry.

## Збірка
1. Відкрийте папку `BookMetaAndroid` в Android Studio (Giraffe або новішій).
2. Дочекайтеся Gradle Sync.
3. Запустіть на пристрої з Android 8.0+.

## Безпека даних
Застосунок не завантажує самі книги в інтернет: у Google Books надсилається лише введений пошуковий запит. Перед редагуванням створіть резервну копію оригіналу.
